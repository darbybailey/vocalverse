# VocalVerse

**The AI-powered singing machine built for Mimi MAMEEN music.**


## Overview
VocalVerse empowers artists to generate and manipulate AI-driven vocals with real-time controls and audio board visualization. Designed for professionals seeking speed, control, and quality.


## Core Features
- Voice synthesis with AI
- Real-time waveform visualization
- Full control over audio parameters
- Save/load session presets
- Vocal style customization


## Setup
1. Clone the repo
2. Run `docker-compose up`
3. Open http://localhost:3000 for frontend and http://localhost:8000/docs for backend API


## Technologies
- TensorFlow
- FastAPI
- Web Audio API
- React + D3.js
- SQLite
- Docker
